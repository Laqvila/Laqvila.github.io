    Datenschutz

    Diese Website erhebt keine personenbezogenen Daten, verwendet keine Cookies und bindet keine Dienste Dritter ein.

    Verantwortlicher

    Verantwortlicher für die Website und die Datenverarbeitung ist Senator Etelwardo Sigismondi, erreichbar unter der institutionellen Adresse etelwardo.sigismondi@senato.it.

    Verarbeitete Daten

    Die Website ist statisch: Sie hat keine Formulare, die Daten an einen Server senden, zeichnet die Navigation nicht auf und verwendet keine Analysewerkzeuge. Das Formular auf der Kontaktseite beschränkt sich darauf, eine E-Mail im E-Mail-Programm des Besuchers zu verfassen; nichts wird an diese Website gesendet oder auf ihr gespeichert. An die institutionelle E-Mail-Adresse gerichtete Nachrichten werden nach den Regeln des Senats der Republik behandelt.

    Hosting

    Die Website wird auf GitHub Pages gehostet. Wie jeder Hosting-Dienst kann der Anbieter technische Verbindungsdaten (zum Beispiel die IP-Adresse) zu Sicherheitszwecken gemäß seiner eigenen Datenschutzerklärung aufzeichnen. Diese Website hat keinen Zugriff auf diese Daten und verwendet sie nicht.

    Schriften und externe Ressourcen

    Die Schriftarten werden direkt auf dieser Website gehostet: Der Besuch erzeugt keine Anfragen an Server Dritter, und es werden keine Navigationsdaten an Dritte übermittelt. Links zu externen Websites (Senat, Openpolis, Medien, soziale Netzwerke) sind als solche gekennzeichnet.

    Rechte

    Zur Ausübung der in der Verordnung (EU) 2016/679 vorgesehenen Rechte (Auskunft, Berichtigung, Löschung, Widerspruch) in Bezug auf etwaige per E-Mail gesendete Nachrichten schreiben Sie bitte an die oben angegebene institutionelle Adresse.
